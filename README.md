# CodeOps

CodeOps is a fixed-scope GitHub Actions and CI repair practice. I find the specific cause behind flaky tests, wasteful CI spend, and risky workflow configuration — and fix it, in days, for a fixed price agreed up front. No hourly billing, no open-ended engagements.

## Services

**Flaky Test Repair Sprint — USD 500**
Root-cause your recurring flaky tests instead of re-running and hoping. Delivered as PRs plus a flake inventory with reproduction rates before and after.

**CI Cost Audit + Reduction Sprint — USD 500–650**
Build-once restructuring, proper caching, and matrix trims for workflows that rebuild the world on every push. Delivered as PRs with before/after run-minute comparisons.

**GitHub Actions Security Audit + Hardening Sprint — USD 800**
SHA pinning, least-privilege token permissions, and credential hygiene for your workflows. Delivered as a findings report plus the hardening PRs.

## How engagement works

- **Fixed price**, quoted before work starts. Typical delivery is 2–5 business days.
- **50% prepaid, or the full amount escrowed** via a funded Upwork or Contra milestone — released when the work is delivered.
- **Diagnosis clause:** if the root cause turns out to sit outside the agreed scope, we stop and re-agree scope before anything else is billed; any prepaid amount is refunded minus a USD 50 diagnosis fee.
